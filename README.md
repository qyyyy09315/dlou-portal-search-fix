# 大连海洋大学门户搜索防刷新

非学校官方的 Tampermonkey 用户脚本，版本 1.0.0，MIT 许可证。用于缓解门户综合搜索时整页跳转、搜索词和结果丢失的问题。

## 修复方式

门户搜索输入变化后会防抖调用搜索接口。公共请求封装在缺少登录 token 或收到 401 时跳转到统一登录页，可能导致搜索框和结果丢失。

本脚本替换门户首页 Vue 实例的搜索方法及其防抖函数，按照页面的搜索配置、搜索词及现有 Authorization 凭据调用接口。搜索鉴权失败时保留输入和已有结果，显示持续提示，由用户主动退出并重新登录；不会伪造成功响应。已有结果可能属于之前的搜索，失败提示会说明这一点。

`person` 分类或明确配置为通讯录的搜索接口返回 401/403 时静默跳过，继续搜索其他分类；其他分类的鉴权失败仍显示提示。静默跳过不代表该分类返回了零条结果。

页面刷新后尝试恢复暂存的搜索词。清空搜索框会删除暂存内容并取消尚未完成的搜索。

## 安装和测试

1. 在浏览器中安装 Tampermonkey。
2. 在 Greasy Fork 发布页点击安装，或从本仓库的 `dlou-portal-search-fix.user.js` 原始文件安装；也可新建脚本并粘贴完整内容。
3. 停用其他同类门户搜索修复脚本，再刷新门户页面。

适用页面：`https://my.dlou.edu.cn/frontend/center_portal_dlou/*`，包括首页和新闻公告页顶部的“综合内容”搜索。

输入搜索词，检查是否保留输入、出现正常结果或明确的错误提示；测试清空、连续输入、手动刷新，以及主动退出和重新登录。出现鉴权提示并不表示搜索服务已修好，需要恢复有效登录或由门户维护人员处理。

## 数据与权限

- 搜索词存于当前标签页的同源 sessionStorage，通常在标签页关闭时清除，同源页面脚本也可访问。
- 读取门户现有的 `center_portal_token`，仅在搜索请求中通过 Authorization 头发送到确切的 HTTPS 域名 `my.dlou.edu.cn` 或 `portal.dlou.edu.cn`。不记录或修改 token，不添加第三方请求。
- 脚本的搜索请求不跟随 HTTP 重定向。其他页面功能沿用门户原有行为。
- 依赖门户 Vue 实例和搜索配置结构，门户改版后可能失效。

## 验证与限制

已在 Edge 验证搜索遇到 401 时保留输入、清空后移除提示、刷新后恢复搜索词，以及首页和新闻公告页顶部搜索。已观察到内容中心和业务系统结果正常展示，而 `person` 分类返回 401。最终静默跳过逻辑通过本地模拟测试，并收到使用者运行正常的反馈。

本地模拟还覆盖缺少凭据、正常响应、搜索词编码、域名限制、过时响应取消和可选分类 401/403 后继续处理其他分类。退出重登及更多浏览器、账号权限组合尚未完整验证。

脚本不能授予接口访问权限或修复服务器鉴权。门户改版后可能需要更新。报告问题时请说明浏览器、脚本管理器版本和复现步骤，避免公开账号、token、Cookie 和敏感搜索词。
